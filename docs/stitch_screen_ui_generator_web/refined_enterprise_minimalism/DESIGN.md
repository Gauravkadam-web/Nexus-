## Brand & Style

This design system delivers an executive, quiet-confidence atmosphere engineered for cognitive clarity in high-density operations. Its brand personality embodies refined modernism: calm, rigorously structured, hyper-legible, and respectful of operator attention. Rather than competing for cognitive bandwidth through saturated notifications and skeuomorphic flourishes, it creates a serene digital workspace that reduces cognitive fatigue during critical investigations.

### Key Tenets
- **Airy Precision:** Generous negative space balances information-dense triage tables and multi-pane investigative workflows.
- **Ambient Intelligence:** Machine learning features do not dominate or interrupt; AI interventions present as organic, polite collaborators tinted in calming lilac with explicit review actions.
- **Tonal Subtlety:** High contrast is preserved strictly for critical readable text, while UI chrome, cards, and structural rails rely on hairline boundaries and delicate pastel washes.

## Colors

The palette leverages a low-strain foundation pairing crisp white surfaces with an ultra-soft cool canvas (`#FAFAFC`). Semantics are communicated through an intentional sRGB pastel system: solid ink foregrounds matched with delicate tinted fills. This creates unequivocal status distinction without visual noise.

### Functional Mapping
- **Primary (`#6366F1`):** Applied to active navigation anchors, primary submission triggers, and focal interactive elements.
- **AI Intelligence (`#9333EA` / `#FAF5FF` / `#C084FC33`):** Applied exclusively to Copilot assistance, automated summaries, and system-generated suggestions.
- **Neutral & Surface Hierarchy:** Background canvas (`#FAFAFC`), resting container surface (`#FFFFFF`), and elevated popover surfaces (`#F8FAFC`). Borders maintain a consistent 1px hairline stroke (`#E2E8F0`).
- **Semantic Status Spectrum:**
  - *Reported:* Slate (`#64748B` / `#F1F5F9`)
  - *Understood / Triage:* Sky (`#0284C7` / `#E0F2FE`)
  - *Assigned:* Periwinkle (`#6366F1` / `#EEF2FF`)
  - *Investigating / In Progress:* Butter Honey (`#D97706` / `#FEF3C7`)
  - *Waiting for Info:* Warm Apricot (`#EA580C` / `#FFEDD5`)
  - *Resolution Proposed:* Iris Lilac (`#7C3AED` / `#F3E8FF`)
  - *Closed / Confirmed:* Sage Teal (`#0D9488` / `#CCFBF1`)
  - *Breached / High Risk:* Coral Rose (`#E11D48` / `#FFE4E6`)

## Typography

The typographic hierarchy implements a structural duality: `Outfit` delivers modern, architectural authority to structural titles and workspace headings, while `Inter` provides neutral, highly legible rhythm across data-dense tables, investigative case notes, and metadata chips.

- **Headlines (`Outfit`):** Characterized by tight letter tracking (`-0.02em` to `-0.01em`) and medium weights (`500` / `600`) to present an editorial, executive finish without shouting.
- **Body & Data (`Inter`):** Renders at a relaxed line height (`22px` on `14px` base font size) to support long reading sessions during audits.
- **Labels & Micro-Tags:** Render at `11px` or `12px` with expanded letter-spacing (`+0.04em`) and uppercase treatment for unambiguous parsing of status flags and SLA deadlines.

## Layout & Spacing

The layout is built on a spacious 8pt grid system. Generous internal padding prevents density from feeling congested, establishing immediate visual hierarchy through negative space.

### Breakpoints & Grids
- **Desktop (>= 1200px):** Multi-pane operational layout featuring an expansive 3-column studio grid (25% triage rail / 50% case timeline & workspace / 25% AI copilot and case attributes) or a 2-column split (65% data canvas / 35% detail inspection). Margins and gutters lock to `32px` (`2rem`).
- **Tablet (600px - 1199px):** Adaptive 2-column view utilizing a collapsible navigation rail and slide-over inspector drawers with `24px` (`1.5rem`) margins.
- **Mobile (< 600px):** Single-column stacked layout with an 85% draggable bottom sheet for contextual drawer contents, anchored with `16px` (`1rem`) outer canvas gutters.

### Component Spacing Discipline
- **Table Cells:** `16px` horizontal, `18px` vertical padding for breathing room between dense records.
- **Standard Card Surfaces:** `24px` internal padding for dashboard cards; `32px` for auth panels and completion modals.

## Elevation & Depth

This design system avoids heavy drop shadows, neon glows, and muddy layering. Elevation is expressed primarily through crisp hairline boundaries, tonal shifts, and low-opacity ambient diffusion.

### Elevation Strategy
- **Layer 0 (Canvas):** Tone `#FAFAFC` serves as the global foundational plane.
- **Layer 1 (Card & Content Blocks):** Resting `#FFFFFF` surfaces bounded by a crisp hairline border (`1px solid #E2E8F0`). Flat elevation with zero blur.
- **Layer 2 (Floating Popovers & Flyouts):** Surfaces using `#F8FAFC` or `#FFFFFF` backed by a faint ambient shadow: `0 4px 20px -2px rgba(15, 23, 42, 0.04), 0 2px 6px -1px rgba(15, 23, 42, 0.02)`.
- **AI Recommendation Micro-Cards:** Elevated through a signature micro-tint wash (`#FAF5FF`) bound by a lilac hairline stroke (`1px solid #C084FC33`), floating contextually inside standard panels without card drop shadows.

## Shapes

The design system pairs structural, geometric surfaces with fully pill-shaped indicators to distinguish operational zones from semantic tags.

- **Containers, Cards, & Dialogs:** Set to level `2` (`0.5rem` / `8px` corner radius for interactive controls; `0.75rem` / `12px` to `1rem` / `16px` for outer cards and modals). This geometry maintains an architectural, enterprise feel.
- **Semantic Pills & Tags:** Full rounded radius (`9999px`) applied to status pills, category filters, SLA indicators, and demo switcher pills.
- **Interactive Inputs:** Bounded with a uniform `8px` corner radius and `48px` standard desktop height.

## Components

### Buttons
- **Primary:** Background `#6366F1`, text `#FFFFFF`, height `40px` (standard) or `48px` (hero/auth), radius `8px`. Subtle hover darkening to `#4F46E5`.
- **Secondary / Outlined:** Background `#FFFFFF`, border `1px solid #E2E8F0`, text `#0F172A`. Hover background `#F8FAFC`.
- **AI Tri-Action Buttons:** Ghost-styled contextual buttons inside lilac containers:
  - *Accept:* Text `#7C3AED`, background `#FAF5FF`, hover `#F3E8FF`.
  - *Modify:* Text `#475569`, background transparent, hover `#F1F5F9`.
  - *Dismiss:* Text `#94A3B8`, hover text `#E11D48`.

### Status Chips & Pills
- Built with a full-pill radius (`9999px`), `4px 10px` padding, font size `11px`, weight `600`, letter spacing `+0.04em`, uppercase text.
- Pair the defined pastel background with its saturated status ink (e.g., `#CCFBF1` fill with `#0D9488` text for *Closed / Confirmed*).
- Optional `6px` solid status circle dot positioned to the left of the label.

### Data Tables
- Header: `#F8FAFC` background, `12px` uppercase `#475569` labels, border bottom `1px solid #E2E8F0`.
- Rows: `#FFFFFF` resting background, vertical cell padding `18px`, horizontal cell padding `16px`, row dividers `1px solid #E2E8F0`. Hover row shift to `#FAFAFC`.

### Form Fields & Search Bars
- Resting state: Height `48px`, background `#FFFFFF`, border `1px solid #E2E8F0`, radius `8px`, padding `0 16px`, text `#0F172A`, placeholder `#94A3B8`.
- Focus state: Border color `#6366F1`, ring outline `2px solid #EEF2FF`.
- Global search includes a keyboard shortcut badge (`Ctrl + K`) styled in `#F1F5F9` with `#64748B` label text.

### AI Suggestion Micro-Cards
- Structural container with background `#FAF5FF`, border `1px solid #C084FC33`, padding `16px 20px`, radius `12px`.
- Header row includes a sparkle icon `✨` in `#9333EA`, followed by a concise recommendation headline and an inline tri-action trigger row.

### Cards & Panels
- Resting container with background `#FFFFFF`, border `1px solid #E2E8F0`, radius `12px`, padding `24px` to `32px`.
- Card headers maintain clean title grouping with body copy separated by `24px` vertical margins.
